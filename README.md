# MakerWorks Lab website

A multi-page static website for [MakerWorks Lab](https://makerworkslab.in/), a robotics and Physical AI maker space in Malad East, Mumbai. HTML, CSS and Bootstrap.

**Live:** https://makerworkslab.in/maker-works.com/

## Pages

- `index.html`: home
- `aboutus.html`: about the lab
- `beginnerlevel.html`, `innovatorlevel.html`, `PORTFOLIOBUILDINGLEVEL.html`: the programme levels
- `Gallery.html`: photos of student projects
- `blog1.html`: blog
- `learn.html`, `makers.html`: learning and community pages
- `images/`: photos and graphics

## Run it

Open `index.html` in a browser, or serve the folder with any static server.

Built by [Ajay Ummadi](https://makerworkslab.in/ajayummadi/) at [MakerWorks Lab](https://makerworkslab.in/), Mumbai.
